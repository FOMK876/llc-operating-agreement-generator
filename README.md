# LLC Operating Agreement Generator

A simple CLI tool that generates a foundational operating agreement template for a new LLC.

## How to Run

1. Navigate to the directory:
```bash
cd llc-operating-agreement-generator
```

2. Run the script with no arguments to generate the template to your current directory:
```bash
node generate-llc-agreement.js
```
*(Or use python: `python3 generate-llc-agreement.py`)*

A file named `llc_operating_agreement_template.txt` will be created.
